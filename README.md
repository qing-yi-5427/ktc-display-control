# KTC 显示器控制台

面向 Apple Silicon Mac 的本地 SwiftUI 显示器控制工具，针对 **KTC M27P20P** 的控制码做了适配。非 KTC 官方软件。

## 功能

- 画面：亮度、对比度、锐度、暗部平衡、分区调光、HDR、图像比例。
- 色彩：色温、Gamma、色域、低蓝光、RGB 增益、六轴色相与饱和度。
- 声音：音量、静音。
- 游戏与连接：同步、响应加速、超频、FPS、DSC、KVM、RGB 灯效。
- 菜单：OSD 位置、显示时间、透明度。
- 配置备份与导入：JSON 文件、导入预览、自动保存导入前副本、逐项回读验证。
- 电源唤醒、原始 VCP 访问、只读扫描和日志导出。

应用不使用网络，不添加开机启动或后台服务。配置文件保存到用户选择的位置，自动恢复副本位于 `~/Library/Application Support/KTCControl/Backups`。用户选择的位置可能由系统的云盘服务同步。

## 下载与使用

从 [Releases](../../releases) 下载 App 压缩包，解压后将 App 放到“应用程序”中打开。发布版本为 Apple Silicon 本地签名构建，没有 Apple 开发者公证；macOS 可能提示无法验证开发者，也可以自行从源码构建。

显示器需要启用 DDC/CI，并通过支持 DDC 通信的连接接入。已在 M1 Mac 和 M27P20P 上验证读取；其他显示器的私有控制码可能完全不同，不应直接套用。

在“配置备份”中保存当前设置，导入时先查看差异。可能中断连接的 DSC、KVM、同步、超频、图像比例默认跳过。电源、输入源、复位、固件和未知指令不参与自动恢复。导入失败会停止后续写入，已经应用的设置保留，可使用导入前副本恢复。

## 构建

需要 Apple Silicon Mac 和 Xcode Command Line Tools，应用最低系统版本声明为 macOS 13。当前验证构建环境为 Swift 6.4 / macOS 27.2 SDK；更旧 SDK 尚未验证。

```sh
./build.command
```

生成 `build/KTC 显示器控制台.app`。如果 iCloud 桌面或文稿目录产生 FinderInfo 签名错误，请复制源码到普通本地目录构建。

配置校验测试（不会操作显示器）：

```sh
./test.command
```

## 已知限制与验证

- 实机成功备份 39 项；使用相同配置进行导入，默认跳过 5 项连接设置，其余 34 项回读一致，并生成导入前副本。
- 配置 JSON 往返及 9 类无效配置校验通过；不同取值的完整批量恢复尚未实机验证。
- HDR、色域和场景模式可能锁定或联动其他设置，写入后以回读结果为准。
- 显示器完全断开时 DDC 无法保证唤醒；尚未确认可用的独立“深度睡眠”开关。
- 输入源、场景模式等未完整解释的值只提供原始访问，不推测厂商私有枚举。
